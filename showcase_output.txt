╭──────────────────────────── Random Walk Problem ─────────────────────────────╮
│ **Answer Overview**                                                          │
│                                                                              │
│ For a robot that moves on an infinite square lattice (one step = up, down,   │
│ left, right) the number of *different* paths that start at the origin, take  │
│ exactly **N** steps and end again at the origin is                           │
│                                                                              │
│ [                                                                            │
│ \boxed{                                                                      │
│ \displaystyle                                                                │
│ \text{paths}(N)=                                                             │
│ \begin{cases}                                                                │
│ \displaystyle \binom{N}{\,N/2\,}^{2}, & N\ \text{even}\[1.2ex]               │
│ 0, & N\ \text{odd}                                                           │
│ \end{cases}}                                                                 │
│ \]                                                                           │
│                                                                              │
│ In words: the walk must have the same number of “up” as “down” steps and the │
│ same number of “left” as “right” steps, which is possible only when **N** is │
│ even.                                                                        │
│ For **N = 10** (i.e. 5 “up‑down” pairs and 5 “left‑right” pairs)             │
│                                                                              │
│ [                                                                            │
│ \binom{10}{5}=252\qquad\Longrightarrow\qquad                                 │
│ \text{paths}(10)=252^{2}=63\,504.                                            │
│ \]                                                                           │
│                                                                              │
│ Below you will find the derivation of the formula, a quick sanity check with │
│ small values, and a compact Python implementation that works for any         │
│ non‑negative integer **N**.                                                  │
│                                                                              │
│ ---                                                                          │
│                                                                              │
│ ## 1.  Why the formula works                                                 │
│                                                                              │
│ Let                                                                          │
│                                                                              │
│ * a = # of steps **up**                                                      │
│ * b = # of steps **down**                                                    │
│ * c = # of steps **left**                                                    │
│ * d = # of steps **right**                                                   │
│                                                                              │
│ The walk ends at the origin iff the vertical displacement is zero **and**    │
│ the horizontal displacement is zero:                                         │
│                                                                              │
│ [                                                                            │
│ a-b=0,\qquad c-d=0\;\Longrightarrow\;a=b,\;c=d.                              │
│ \]                                                                           │
│                                                                              │
│ The total number of steps is                                                 │
│                                                                              │
│ [                                                                            │
│ a+b+c+d = 2a+2c = N .                                                        │
│ \]                                                                           │
│                                                                              │
│ Hence **N must be even**; write `N = 2M` (so `M = N/2`).                     │
│ Then we have the free choice of how many of the `M` vertical‑step pairs are  │
│ “up‑down” (`a`) and how many are “horizontal” (`c`):                         │
│                                                                              │
│ [                                                                            │
│ a\in\{0,1,\dots,M\},\qquad c = M-a .                                         │
│ \]                                                                           │
│                                                                              │
│ For a fixed pair `(a,c)` the robot can arrange its steps in any order, which │
│ is counted by the multinomial coefficient                                    │
│                                                                              │
│ [                                                                            │
│ \frac{N!}{a!\,b!\,c!\,d!}= \frac{N!}{a!^{2}\,c!^{2}} .                       │
